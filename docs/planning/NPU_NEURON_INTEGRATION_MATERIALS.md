# 传统 NPU + ENeuron 集成材料包草案

状态：`DRAFT / ADMIN_REVIEW_REQUIRED`

日期：2026-09-03

适用范围：进入传统 NPU + ENeuron 集成实现前的静态材料包。本文不授权业务 RTL、Vivado 或板级测试；所有“建议冻结”均不是已经批准的项目合同。

## 1. 为什么要先补这份材料

仓库当前已经有 ENeuron、Pulse-Mini-L/L2、NP7 共享 BRAM/lane 和局部 `2:4` 门控证据，但没有一个可作为传统 NPU 基线的完整 INT8 乘加数据通路。若直接把 NP7 的突触执行器称为 NPU，会混淆以下三件事：

1. NPU 的数值乘加、累加、偏置、激活和输出量化；
2. ENeuron 产生局部门控或剪枝决策；
3. 网口、DMA、PS 和 FPGA 顶层的供数与回收。

本材料包先把第一项和第二项的最小接口写清楚，第三项暂时保持单时钟、片上固定向量，避免把网口问题掺入第一轮功能证明。

## 2. 首个传统 NPU 候选模型（待批准）

### 2.1 推荐基线：8×8 灰度 MLP `64 → 32 → 10`

| 项目 | 建议候选值 | 选择理由 |
|---|---|---|
| 输入 | 固定 8×8 灰度图，64 个元素 | 与仓库已有数字识别数据和报告一致，输入规模小且可复现 |
| 隐藏层 | 32 个神经元 | 有足够多的四权重组，能观察门控收益，又不会先被系统规模掩盖 |
| 输出层 | 10 个 logits | 对应十分类；输出通道数不要求是 4 的倍数 |
| 层类型 | 两层全连接，不加入卷积 | 先隔离局部门控和 INT8 GEMM 语义，减少地址与边界变量 |
| 激活 | 隐藏层 ReLU，再截断到有符号 INT8 可表示的非负范围 | 硬件简单，避免第一轮引入复杂激活查表 |
| 输出判定 | 取 10 个 logits 的唯一最大值；全零、并列或非法多脉冲输出为 `abstain` | 与已有神经元任务的严格解码口径一致 |

该模型只是推荐的**第一轮测试对象**，不是项目已经冻结的模型。若管理员希望先测更小版本，可将隐藏层改为 16，但必须保持同一输入、量化、门控和验收协议，不能用更小模型替代推荐模型后宣称规模结论。

### 2.2 候选定点格式

- 像素输入：无符号 4 bit，取值 `0..15`；进入 NPU 后零扩展为有符号 8 bit。
- 权重：二补码有符号 INT8，范围 `-128..127`。
- 偏置：有符号 INT32。
- 乘加累加器：有符号 INT32。第一层最坏乘积和远低于 INT32 上限，暂不需要依赖溢出行为。
- 隐藏层输出：先加偏置，再执行 ReLU，最后饱和到 `0..127` 的 INT8。
- 输出层：INT32 logits 只读出，不在第一轮再量化；比较器使用完整 INT32 值。
- 舍入/移位：第一版不做隐含右移；若后续需要缩放，必须新增明确的 `quant_shift` 字段并重新生成所有黄金向量。

### 2.3 权重分组与门控粒度

每个输出通道沿输入维度按四个权重分组：

- 隐藏层：每个输出通道 `64 / 4 = 16` 组，共 `32 × 16 = 512` 组。
- 输出层：每个输出通道 `32 / 4 = 8` 组，共 `10 × 8 = 80` 组。
- 每组的门控最小单位是“整组是否发出数值乘加”，不直接关闭任意单个 DSP/MAC。
- 若采用结构 `2:4`，组内保留两个权重及其位置索引；结构掩码与活动门控必须分开计数。

这样既能复用 NP7 已证明的四权重组和 `2:4` 存储思想，又不把 NP7 的二值事件加法误当作 INT8×INT8 乘法器。

## 3. 集成边界与逐周期协议候选

### 3.1 第一阶段边界

第一阶段只做单时钟片上 OOC：固定向量由 testbench 或片上配置 RAM 提供，暂不接 AXI、网口、PS 软件和异步 FIFO。这样可以先回答“门控是否改变 NPU 结果、读取量和周期”，再单独接入网口。

### 3.2 NPU 数据通路候选端口

| 方向 | 信号 | 语义 |
|---|---|---|
| 输入 | `sample_start` | 接受一份样本；空闲时才可握手 |
| 输入 | `act_valid/act_ready/act_data` | 按固定顺序发送 64 个或 32 个 INT8 激活 |
| 输入 | `weight_cfg_valid/ready` | 仅配置窗口写入权重和偏置；运行期只读 |
| 输出 | `npu_done` | 该样本所有输出通道完成 |
| 输出 | `logit_valid/ready/logit_data` | 有序发出 10 个 INT32 logits |
| 输入 | `infer_freeze` | 推理窗口冻结权重、门控状态和学习状态 |

所有接口使用 `valid && ready` 作为唯一接受条件。结果输出不得组合反向驱动 ENeuron 的决策，也不得在结果未被接受时覆盖。

### 3.3 ENeuron 门控旁路候选端口

| 方向 | 信号 | 语义 |
|---|---|---|
| 输入 | `group_summary_valid/ready` | 发送一个局部组的活动摘要 |
| 输入 | `group_id` | 层、输出通道和组号的稳定寻址值 |
| 输入 | `activity[3:0]` | 四个输入位置的活动摘要；不携带 NPU 最终结果 |
| 输出 | `gate_decision_valid/ready` | 输出该组是否允许发出数值乘加及可选 `2:4` mask |
| 输入 | `mask_commit_valid/ready` | 在批边界提交整批门控结果 |
| 输入 | `mask_epoch` | 单调递增的提交编号，便于账本核对 |
| 输出 | `mask_active_epoch` | 当前 NPU 正在使用的门控版本 |

门控决策先进入单槽待提交区；`mask_commit` 握手前不得改变正在计算的样本。`mask_commit` 在两个样本之间原子生效，禁止半批生效。

### 3.4 参考时序

```text
S_IDLE
  -> LOAD_SAMPLE
  -> COLLECT_GROUP_SUMMARY
  -> WAIT_MASK_COMMIT
  -> RUN_LAYER_0
  -> RUN_LAYER_1
  -> EMIT_LOGITS
  -> S_IDLE
```

ENeuron 的状态更新和 NPU 的乘加执行在逻辑上分离。门控位图在 `RUN_LAYER_0/RUN_LAYER_1` 开始前锁存；计算中途的候选更新只进入下一 epoch。

## 4. 必须覆盖的最坏情况矩阵

| 场景 | 必须观察 | 预期结果 |
|---|---|---|
| 全开 | 所有组都允许执行 | 与无门控传统 NPU 逐 logit、逐计数 bit-exact |
| 全关 | 所有组都跳过 | 乘加数为 0，但样本/层状态仍按合同推进；输出按固定 bias 规则产生 |
| 频繁切换 | 每个样本切换门控 epoch | 只在批边界切换，不出现半旧半新 mask |
| 零活动 | `activity=0` 且门控关闭 | 不发权重读和 MAC 请求；不跳过事务完成和状态计数 |
| 结果背压 | `logit_ready=0` | logits、epoch、计数器稳定，不能接受下一样本覆盖结果 |
| 配置背压 | `cfg_ready=0` | 配置字保持，不能部分写入或误改变运行期权重 |
| 状态清除 | 清动态状态但保留已提交结构 mask | 下一样本从定义的初态开始，mask epoch 不回退 |
| 推理冻结 | `infer_freeze=1` | 权重、mask、ENeuron 学习状态逐字段不变 |
| 非法地址/索引 | 越界 group、重复 `2:4` 索引 | 配置握手失败并置错误标志；RAM 不写入 |

## 5. 验收门槛（候选）

以下门槛用于提交给管理员审核，尚未生效：

1. 旁路模式与传统 NPU 基线在固定向量上逐输出 bit-exact。
2. 全开门控与旁路模式的权重、激活、logit、完成顺序和总周期逐字段一致。
3. 全关、零活动、背压、清除和频繁切换均通过逐周期参考模型与 RTL 协同仿真。
4. 门控只减少实际接受的组读请求和 MAC 发射；“读完后再清零”以及“MAC 后清零”负向实现必须被性能检查拒绝。
5. 至少 20 个固定随机种子、每个至少 100 个样本；训练与推理分开，推理期间权重和门控状态逐字段冻结。
6. 首轮性能分别报告：总组数、有效组读、有效 MAC、总周期、输出吞吐、旁路/门控准确率、abstain 率和 mask churn。
7. 资源与时序门绑定 `xc7z020clg400-1`、确切 Vivado 版本和 Git HEAD；不使用 NP7 周期收益替代集成级 routed 证据。

## 7. 批准后的最小实施顺序

```text
管理员裁定 I1-I6
  -> Python INT8 NPU 旁路/门控参考模型
  -> 固定向量与最坏情况矩阵
  -> 独立 NPU OOC RTL
  -> ENeuron gate wrapper
  -> 逐周期协同仿真、形式与负向控制
  -> 资源/时序 runner
  -> XC7Z020 顶层
  -> 最后接网口/DMA/PS
```

任何一层失败都保留失败证据，不降低准确率、周期或 bit-exact 门槛来换取继续推进。
