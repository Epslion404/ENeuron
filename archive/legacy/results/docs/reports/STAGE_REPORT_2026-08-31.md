## 1. 摘要

本项目已经把一个最初的“数字脉冲神经元电路想法”，推进为一套可以进行定点建模、RTL 实现、协同仿真、有限形式验证、Vivado 综合和布局布线检查的数字可塑神经元硬件基石。

当前已经证明的核心闭环是：片外 Host 提供神经元级训练信号，片上神经元保存局部事件历史并计算资格状态，片上完成有符号权重更新，随后切换到 INFER 模式冻结学习状态完成推理。多个神经元已经组成固定 `4→2→2` 网络，并完成一拍隐藏层路由、训练、提交、读回和冻结推理。

项目还完成了三种神经元模型接入局部严格 `2:4` 剪枝控制器的功能签核。剪枝在模型层面减少了约 31% 的连接发射工作，但尚未证明 FPGA 墙钟加速、BRAM 真跳读、面积下降或功耗下降。PR #2 已把套件内 Vivado 短回归补齐为 ENeuron、Pulse-Mini-L、Pulse-Mini-L2 三模型覆盖，避免“证据层覆盖三模型、快速测试只跑两模型”的口径缝隙。

因此，当前最准确的定位是：

> 已验证的数字可塑脉冲神经元和固定小网络硬件基石，附带已完成行为级签核的局部自动剪枝控制器；尚不是通用 AI、实用规模 NPU 或板级产品。

## 2. 原始目标与方案演进

最初方案将树突和胞体设计为计数器、分频器和复位/睡眠计数器的组合：输入事件经过学习计数和分频后进入胞体，胞体累加输入并在达到阈值后发放脉冲。

这个结构适合验证“事件积分和发放”，但不能直接成为可靠的 AI 学习基石，原因包括：

- 学习方向主要是单向增强，缺少稳定的抑制机制；
- 计数器上限和回绕会改变权重含义；
- 没有清晰的延迟反馈和任务信用分配机制；
- 分频器、派生时钟和内部复位不利于 FPGA 时序收敛；
- 无法审计训练是否真正来自神经元本地状态。

项目因此形成了三个层次：

1. 原始计数/分频单元作为成本和缺陷基线；
2. Pulse-Mini-L/L2 作为低成本复制和算法实验版本；
3. ENeuron 作为学习状态更完整、证据链更强的基准版本。

## 3. 当前硬件架构

### 3.1 ENeuron 单元

完整神经元包含：

- 有符号突触权重；
- 输入电流和膜状态；
- 膜电位缓慢泄放；
- 输入和输出近期历史；
- 每条连接的资格状态；
- eligibility snapshot；
- 有符号调制输入；
- 饱和权重更新；
- 阈值发放和不应期；
- TRAIN/INFER 隔离。

训练流程为：输入事件产生局部历史，episode 结束时锁存资格状态，Host 提供正、负或零调制，片上依据资格状态完成权重更新。Host 可以提供标签、奖励、探索策略和调度，但训练期间不直接写入权重。

### 3.2 固定 `4→2→2` Tile

```text
4 个输入事件通道
        ↓
2 个隐藏神经元
        ↓  一拍逻辑延迟
2 个输出神经元
```

Tile 并行实例化四个多周期神经元核。隐藏层在 tick `t` 的结果保存为 pending 状态，输出层只能在 tick `t+1` 读取上一拍结果。所有子核完成后，Tile 通过完成屏障原子公布外部结果。

当前协议采用单槽 snapshot/pending 设计，适合固定小网络，不支持多个乱序未决提交。

### 3.3 双时钟 Host Bridge

Host Bridge 使用命令 FIFO、响应 FIFO、控制器和官方 XPM 异步 FIFO，连接 Host 时钟域与 Tile 时钟域，覆盖背压、顺序响应和 hard reset。

这一层使训练调制和状态读回可以跨时钟域传输，同时保持命令合同和错误隔离。第一版协议固定服务当前 `4→2→2` 网络，不是通用大规模网络协议。

## 6. FPGA 资源与时序

### 6.1 XC7Z020 单核

条件为 Vivado 2024.1、`xc7z020clg400-1`、100 MHz、OOC post-route。

| 单元 | LUT | FF | BRAM | DSP | WNS | 结论 |
|---|---:|---:|---:|---:|---:|---|
| 原始计数/分频 | 183 | 85 | 0 | 0 | -1.605 ns | 失败 |
| Pulse-Mini-L | 182 | 76 | 0 | 0 | +0.463 ns | 通过 |
| Pulse-Mini-L2 | 366 | 91 | 0 | 0 | -4.690 ns | 失败 |
| ENeuron，2 输入 | 718 | 380 | 0 | 0 | +0.418 ns | 通过 |
| ENeuron，4 输入 | 818 | 544 | 0 | 0 | +0.431 ns | 通过 |

Pulse-Mini-L 是当前最适合大量复制的低成本版本；ENeuron 资源较高，但局部学习状态更完整；Pulse-Mini-L2 的证据强度更丰富，但需要拆分或流水化学习路径后才能恢复 100 MHz。

### 6.2 Tile 和 Host Bridge

在 `xc7a35tcpg236-1` 上完成的 OOC post-route 结果：

| 实现 | LUT | FF | BRAM | DSP | WNS |
|---|---:|---:|---:|---:|---:|
| 多周期单核 | 813 | 544 | 0 | 0 | +0.469 ns |
| 固定 `4→2→2` Tile | 3152 | 1972 | 0 | 0 | +0.213 ns |
| Host Bridge + Controller + Tile | 3682 | 2486 | 4 RAMB36 | 0 | +0.081 ns |

系统 Host 时钟为 50 MHz，Tile 时钟为 100 MHz。两时钟域的 setup/hold、TNS/THS、route error 和 DRC Error/Critical Warning 均为 0。系统 `0.112 W` 为无真实活动文件的 Medium-confidence vector-less 估算，不能视为板级功耗。

### 6.3 Pulse-Mini-L 阵列

简单广播阵列的已验证边界为：

| 并行核数 | LUT | FF | WNS @100 MHz | 结论 |
|---:|---:|---:|---:|---|
| 32 | 5867 | 2432 | +0.151 ns | 通过 |
| 64 | 11699 | 4864 | -0.131 ns | 时序失败 |
| 128 | 23342 | 9728 | -0.466 ns | 时序失败 |

64 和 128 核主要受输入广播、控制扇出和路由拥塞影响，不是简单的 LUT 容量问题。因此当前只能把 32 核称为已证明的 100 MHz 并行点。

## 7. 局部自动剪枝结果

NP4B 采用严格 `2:4`：每四条连接始终保留两条。控制器在权重读取和计算发射前形成 `issue_mask`，被剪连接不得继续读取、发射或更新。

已完成内容：

- ENeuron、Pulse-Mini-L、Pulse-Mini-L2 三种模型接入；
- 固定 `4→8→2` 网络端到端验证；
- 一次原子 `PRUNE_COMMIT`；
- 固定低索引 tie-break；
- utility 饱和；
- 非法命令和非法 mask 无副作用；
- INFER 模式拒绝观察和剪枝提交；
- commit 后自动清除动态历史；
- 被剪权重、utility 和 evidence 不再非法变化。

逻辑账本显示：

| 模型 | 隐藏层节省 | 输出层节省 | 总体节省 |
|---|---:|---:|---:|
| Pulse-Mini-L | 32.74% | 26.49% | 31.71% |
| Pulse-Mini-L2 | 31.57% | 30.17% | 31.21% |

这些是逻辑 issue/发射工作量，不是 FPGA 物理加速。真实 BRAM 跳读、周期下降、功耗下降和 XC7Z020 时序收益属于尚未批准的 NP6/NP7 阶段。

截至 `e5bbbc5`，局部剪枝相关的最新主线状态是：PR #1 提供三模型完整行为级 Vivado/XSim 证据，PR #2 补齐三模型快速 Vivado 测试覆盖。二者共同提升的是验证链完整性，而不是剪枝硬件物理收益本身。

## 8. 数字识别实验

### D0/D1：输入编码和软件可分性

项目使用 1797 张 8×8 数字图像，训练/验证/测试划分为 1252/270/275。每张图选择最亮的 16 个像素，并使用 16 tick rank-order latency 编码。

软件最近质心基线达到：

- Test Balanced Accuracy：79.80%；
- Accuracy：80.00%；
- Macro-F1：79.46%；
- 标签打乱后约 8.69%。

这说明编码中确实包含空间和亮度信息。

### D2：神经元网络训练失败

D2 使用 `64→16→4→10` 网络，共 30 个神经元和 120 条逻辑连接。10 个随机种子、3 个 epoch 的测试结果为：

- Validation BAcc 平均：4.61%；
- Test BAcc 平均：4.74%；
- Test coverage 平均：52.18%；
- 达到强门槛的 seed：0/10。

失败原因主要是固定特征压缩过强，以及十分类中“一正九负”的调制不平衡，使输出权重趋同，产生单一类别、并列或弃权。该结果说明当前硬件闭环存在，但当前网络和学习协议还不能完成实用数字识别。

## 9. 项目意义

### 9.1 从概念推进到可审计硬件

项目建立了完整的工程闭环：

```text
神经元规则
 → 定点黄金模型
 → SystemVerilog RTL
 → Python/RTL 协同仿真
 → 有限形式验证
 → Vivado 综合与布局布线
 → 时序、CDC 和 DRC 检查
```

这使“神经元能否学习”不再只是软件实验，而成为可以逐事务复现、逐字段核对和逐阶段签核的硬件问题。

### 9.2 证明了片外训练信号与片上局部学习可以结合

当前架构允许 Host 负责复杂的目标和调度，同时让片上神经元保留局部学习状态并完成实际权重变化。这是一个适合 FPGA 原型和后续 NPU 研究的折中：硬件保持简单、学习过程可审计，Host 仍可快速迭代训练策略。

### 9.3 找到了真正的扩展瓶颈

项目已经把主要风险定位为可测量问题：

- 大扇入需要 BRAM 和共享 lane；
- 简单广播阵列受扇出和路由限制；
- 剪枝的逻辑节省必须转化为真实存储访问节省；
- 多层网络需要更好的隐藏层信用分配；
- 数字识别需要更强的输入表示和输出训练协议；
- 板级时钟、I/O、功耗和长期运行尚未验证。

## 12. 最终结论

ENeuron 已完成原始 Goal M1-M4：单神经元、固定小网络、真实 RTL 训练/推理闭环以及 FPGA 数字前端物理签核均已建立。Pulse-Mini-L 证明了低成本版本可以在 100 MHz 下复制，NP4B 证明了三种神经元都可以接入严格 `2:4` 局部剪枝控制器。PR #2 合并后，快速 Vivado 集成测试也覆盖了 ENeuron、Pulse-Mini-L、Pulse-Mini-L2 三个模型。

项目的阶段性成果不是“已经做出一个通用 AI 芯片”，而是建立了一个可信的硬件研究基石：规则明确、状态可审计、训练来源可追溯、RTL 与软件可对拍、协议可形式检查、物理实现有真实数据。后续真正的核心工作，是把这个小规模、行为上成立的基石推进到共享存储、可扩展阵列、真实板级 I/O 和可量化的物理收益。
