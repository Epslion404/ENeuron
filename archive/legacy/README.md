# 历史归档

这里保存不再参与当前日常开发门的研究线和旧物理证据。归档只改变工作区入口，不删除 Git 历史，也不把旧结果当作当前器件或当前 RTL 的证明。

## 分类

- `pulse_mini/`：Pulse-Mini-L/L2、旧局部剪枝实验及其报告。
- `digit8x8/`：数字识别实验线。
- `g4/`：G4 多任务研究线。
- `eneuron_v1_host_bridge/`：ENeuron 1.0 Tile、Host Bridge 与旧 `xc7a35t` 物理材料。
- `np6_physical/`、`np7_physical/`：旧 NP6/NP7 物理报告和清单。
- `results/`：不属于当前活动结果布局的历史普通结果。
- `nexus/`：旧 Nexus 原始探针快照。

当前活动入口见仓库根目录 `README.md`、`docs/README.md` 和 `WORKFLOW_STATE.md`。
